# 🎵 - AI音樂創作工具

## 📖 專案介紹
創新的AI音樂創作輔助工具，幫助用戶為特定情境生成專業的AI音樂創作指令。

## ✨ 功能特色
- 🎲 **隨機情境抽取**: 從豐富的情境庫中隨機獲取創作靈感
- 🎼 **音樂元素配對**: 直觀的介面選擇樂器、節拍、氛圍等
- 📋 **一鍵指令生成**: 自動生成標準的AI音樂創作prompt
- 📱 **響應式設計**: 完美支援桌面和行動裝置
- 💾 **自動保存**: 防止創作進度丟失

## 🚀 使用方法
1. **開啟網頁**: 在瀏覽器中開啟 `index.html`
2. **抽取情境**: 點擊「抽取專屬情境」按鈕
3. **選擇元素**: 配置音樂樂器、節拍、氛圍等參數
4. **生成指令**: 獲得完整的AI音樂生成指令
5. **複製使用**: 一鍵複製到Suno、Udio等平台使用

## 🛠️ 技術架構
- **前端**: HTML5 + CSS3 + Vanilla JavaScript
- **樣式**: CSS Grid + Flexbox + 動畫效果
- **功能**: 本地存儲 + 剪貼板API + 響應式設計

## 🎯 支援平台
- Suno AI
- Udio  
- Musicfy
- 其他支援英文prompt的AI音樂平台

## 📱 瀏覽器支援
- Chrome 60+
- Firefox 55+
- Safari 12+
- Edge 79+

## 🔧 部署說明
1. 下載所有檔案到同一資料夾
2. 確保檔案結構正確
3. 使用網頁伺服器開啟 (推薦使用Live Server擴充)
4. 或直接在瀏覽器中開啟 `index.html`
